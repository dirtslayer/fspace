# FsPACE

This is a Love2d hello-world gone wild inspired by Omega Race and Asteroids

## how to install and run for love2d on command line

0. install love2d
1. get the fspace code from github repository
2. change into the fspace code folder 
3. verify contents of folder

.vscode    │ char.lua  │ line_sprite.lua │ rock.lua
README.MD  │ digit.lua │ main.lua        │ ship.lua
bullet.lua │ light.lua │ mine.lua        │ thrust.lua

4. run main.lua from the command line by typing: love .
5. f for fire bullet, space for engage thruster (or mouse left and right buttons)
6. q to quit

## how to debug fspace from vscode

0. install love2d
1. install lua-local vscode extension
2. create a launch.json automatically or copy fspace/.vscode/launch.json
3. place break point by clicking in left column of some code
4. hit f5 / debug run menu item
